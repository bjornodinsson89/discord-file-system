# Happy Jumper Privacy Policy

**Effective Date:** 2025-01-01

This policy explains how Happy Jumper collects, stores, and uses data.

## 1) Data We Collect
- **Discord identifiers:** user IDs, guild IDs, and role/channel IDs required for
  access control and features.
- **Operational data:** sessions, raffles, insurance policies/claims, audit log
  entries, and configuration settings.
- **Torn API Keys:** used for verification and automated checks.

## 2) Torn API Key Handling
- API keys are **encrypted at rest** using a server-side encryption key.
- Keys are only decrypted in memory when performing a Torn API request.
- Keys are never logged or stored in plaintext.

## 3) How We Use Data
- To authenticate users and enforce permissions.
- To run bot features (sessions, raffles, insurance, audit logging).
- To provide operational and moderation tooling to server admins.

## 4) Data Sharing
- We do not sell or share data with third parties.
- Data may be processed by infrastructure providers (e.g., hosting and database
  services) solely for service operation.

## 5) Data Retention
- Data is retained while your server uses Happy Jumper.
- Server administrators may remove data by uninstalling the bot or requesting
  deletion (where applicable).

## 6) Security
- Encryption is used for sensitive credentials.
- Access controls restrict administrative actions to authorized users.

## 7) Updates
- This policy may be updated periodically. Continued use implies acceptance of
  the latest version.
